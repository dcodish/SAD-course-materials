# שלב 3: ניתוח דרישות (Requirements)

אוספים ומנסחים מה המערכת צריכה לעשות. · **בקורס:** הרצאות 3, 4–5.

**הדוגמה הרצה (קמפוס):** דרישות פונקציונליות ולא-פונקציונליות, ותרחישי שימוש (Use Cases) למערכת ההזמנות.

## קריאה

- **[Wetherbe (1991): Executive Information Requirements: Getting It Right](מאמרים/Wetherbe-1991-executive-information-requirements.pdf)**.
  ⚠️ **קריאת חובה לקראת שיעור 3.** המאמר שעליו בנוי כל הדיון על איסוף דרישות: למה שאילת
  מנהלים "מה אתם צריכים?" נכשלת, וארבע השיטות שכן עובדות (ראיון מובנה, JAD, אב-טיפוס,
  ניתוח חוצה-פונקציות).
- [רשימת תיוג לדרישות לא-פונקציונליות](מאמרים/non-functional-requirements-checklist.pdf):
  דף עזר לניסוח NFR: אבטחה, ביקורת, ביצועים, זמינות, שרידות ועוד.

## ✅ [`תוצר-מאומת/`](תוצר-מאומת/): התוצר של האנליסט/ית (ground truth)

דוגמת ייחוס לפרויקט שלכם: התוצרים המלאים של שלב הדרישות, בפורמט הקורס.
כל מסמך מגיע **בשתי גרסאות**: `md` לקריאה נוחה כאן ב-GitHub; `docx`, אותו מסמך
ב-Word (עברית, RTL), כתבנית עבודה לפרויקט שלכם:

- [`מסמך-דרישות-קמפוס.md`](תוצר-מאומת/מסמך-דרישות-קמפוס.md) · [Word](תוצר-מאומת/מסמך-דרישות-קמפוס.docx):
  מסמך הדרישות המלא: מילון נתונים לכל הישויות, דרישות פונקציונליות בשתי רמות
  (FR-1…12, כולל דרישות הליבה), קטלוג חוקים עסקיים (BR), דרישות לא-פונקציונליות (NFR)
  ושאלות פתוחות.
- [`סיפורי-משתמש-קמפוס.md`](תוצר-מאומת/סיפורי-משתמש-קמפוס.md) · [Word](תוצר-מאומת/סיפורי-משתמש-קמפוס.docx):
  אותן דרישות כסיפורי משתמש: סיפור + תנאי קבלה + MoSCoW, וטבלת עקיבות אל ה-FR.
- [`מטריצת-קישור-קמפוס.md`](תוצר-מאומת/מטריצת-קישור-קמפוס.md) · [Word](תוצר-מאומת/מטריצת-קישור-קמפוס.docx):
  מטריצת הקישור בין הדרישות הפונקציונליות לתרחישי השימוש: שורה לכל `FR-n`, עמודה לכל
  תרחיש, וטבלת הדרישות שאין להן תרחיש. זו הבדיקה שמסמך הדרישות ותרשים ה-Use Case מדברים
  על אותה מערכת.

## 🏋️ תרגול (הרצאות 4–5): מהמסמך לתרשים, ואז ביקורת

שני מסמכי אפיון מלאים (100+ דרישות כל אחד) לתרגיל של סוף ההרצאה: מזינים ל-AI,
מקבלים תרשים, ואתם השופטים. לכל אחד מהם גם **דוגמה מלאה בפורמט הפרויקט**: מסמך
הדרישות, סיפורי המשתמש, טבלאות העקיבות ומטריצת הקישור, ותרשים תרחישי שימוש אינטראקטיבי
(לחיצה על תרחיש פותחת את התיעוד המלא שלו).
