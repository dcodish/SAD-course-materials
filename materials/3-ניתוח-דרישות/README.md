# שלב 3 — ניתוח דרישות (Requirements)

אוספים ומנסחים מה המערכת צריכה לעשות. · **בקורס:** הרצאות 3, 4–5.

**הדוגמה הרצה (קמפוס):** דרישות פונקציונליות ולא-פונקציונליות, ותרחישי שימוש (Use Cases) למערכת ההזמנות.

## קריאה

- **[Wetherbe (1991) — Executive Information Requirements: Getting It Right](מאמרים/Wetherbe-1991-executive-information-requirements.pdf)**
  — ⚠️ **קריאת חובה לקראת שיעור 3.** המאמר שעליו בנוי כל הדיון על איסוף דרישות: למה שאילת
  מנהלים "מה אתם צריכים?" נכשלת, וארבע השיטות שכן עובדות (ראיון מובנה, JAD, אב-טיפוס,
  ניתוח חוצה-פונקציות).
- [רשימת תיוג לדרישות לא-פונקציונליות](מאמרים/non-functional-requirements-checklist.pdf)
  — דף עזר לניסוח NFR: אבטחה, ביקורת, ביצועים, זמינות, שרידות ועוד.

_שאר החומרים יתווספו עם התקדמות הקורס._
