# מבחנים

מבחנים שנערכו בקורס, וכן מבחני דוגמה שנכתבו לתרגול.

**האתר לסטודנטים:** <https://dcodish.github.io/SAD-course-materials/exams/>

## מבנה

```
exams/
  index.html                 עמוד הכניסה לסטודנטים
  page.css                   העיצוב המשותף לכל העמודים כאן
  <שנה>/<סמסטר>/<מועד>/       מבחן אחד שנערך בפועל
      index.html             עמוד המבחן, ובתחתיתו תיבת השאלות
      *.docx                 המבחן, ולצדו הפתרון היכן שקיים
  מבחני-דוגמה/                שלושת מבחני התרגול, עם פתרון HTML מלא
```

## כללים

- **מבחן עולה לכאן רק אחרי שנערך.** מועד שטרם התקיים אינו מתפרסם, בשום צורה.
- **הפתרון הוא מחוון הבודק המקורי** (Word), היכן שקיים. מבחני הדוגמה בלבד נושאים
  פתרון HTML מלא עם תרשימים פתורים.
- **הפתרונות הישנים מקדימים שינויים בדוקטרינת הקורס.** עמוד המבחן נושא הערה על כך;
  אין לתקן פתרון היסטורי בדיעבד.
- כל עמוד מבחן נושא תיבת שאלות של giscus, הממופה לפי `pathname` — כלומר דיון נפרד
  נוצר אוטומטית לכל מבחן בפעם הראשונה שסטודנט כותב בו. אין צורך ליצור דיון מראש.

## הוספת מבחן

1. צרו `exams/<שנה>/<סמסטר>/<מועד>/` והעתיקו לתוכו את קובצי ה-Word.
2. העתיקו `index.html` ממבחן קיים והחליפו את הכותרת ואת שמות הקבצים.
3. הוסיפו כרטיס לרשימה ב-`exams/index.html`.
4. פרסמו: `python build_dist.py` מתיקיית השורש, ואז commit ו-push ב-`dist/`.

המקור נמצא כאן בלבד. **אין לערוך דבר תחת `dist/`** — הוא נמחק ונבנה מחדש בכל פרסום.
